# Selecline BM1250C — сайт-инструкция

**Опубликован: https://wwwparser.github.io/selecline-bm1250c/**

Статический сайт с инструкцией, расшифровкой 15 программ и рецептами для хлебопечки
**Selecline BM1250C**. Рассчитан на публикацию через GitHub Pages и на индексацию в Google
и Яндексе по запросам вида «selecline bm1250c инструкция», «рецепты для хлебопечки selecline»,
«почему в углах ведёрка остаётся сухая мука».

Анализ идеи, варианты реализации, риски и оценка — в [PLAN.md](PLAN.md).

Плюс инфографика (всё inline SVG, без картинок): панель управления с дисплеем и 15 программами,
шесть шагов закладки продуктов, три состояния колобка, карточка быстрого старта.

Микроразметка: `Recipe` на каждом рецепте, `HowTo` на инструкции, `FAQPage` на главной,
`BreadcrumbList` везде. Есть `sitemap.xml` и `robots.txt`.

## Сборка

```bash
pip install -r requirements.txt
python build.py            # собрать сайт в docs/
python build.py --serve    # собрать и открыть http://localhost:8000
```

Папку `docs/` не редактируют руками — она пересобирается целиком.

## Публикация

Сайт уже опубликован: **https://wwwparser.github.io/selecline-bm1250c/**
GitHub Pages раздаёт папку `docs/` ветки `main` (Settings → Pages → Deploy from a branch → `main` / `/docs`).

Обновление после правок:

```bash
python build.py
git add -A && git commit -m "Что изменилось" && git push
```

Через минуту-две изменения на сайте.

### Что осталось сделать вручную

1. Добавить сайт в [Google Search Console](https://search.google.com/search-console) и
   [Яндекс.Вебмастер](https://webmaster.yandex.ru/), скормить
   `https://wwwparser.github.io/selecline-bm1250c/sitemap.xml`.
2. Оставить ссылку в теме про BM1250C на hlebopechka.ru и в отзыве на otzovik.com —
   это и живой трафик, и ускорение индексации.
3. Заменить SVG-схемы реальными фото своей печки (панель, ведёрко, колобок на 15-й минуте,
   готовая буханка) — уникальные фото по этой модели усилят страницы.

### Свой домен вместо github.io

Положите файл `CNAME` с доменом в `static/`, добавьте его копирование в `build.py`,
пропишите DNS по инструкции GitHub и поменяйте `site_url` в `data/site.json`.

## Как добавить рецепт

Допишите объект в `data/recipes.json` и пересоберите. Всё остальное — страница, карточка в списке,
строка в сводной таблице, разметка `Recipe`, запись в `sitemap.xml` — появится само.

Поля: `slug`, `emoji`, `h1`, `title`, `description`, `keywords`, `featured`, `program`, `size`,
`crust`, `yield`, `prep_min`, `cook_min`, `lead_html`, `ingredients`, `steps`, `tips_html`, `source_html`.
Иконка ингредиента (`icon`) — одно из: `water`, `oil`, `salt`, `sugar`, `flour`, `yeast`, `milk`,
`butter`, `fruit`, `spice`.

## Как добавить обычную страницу

Создайте файл в `data/pages/`. В начале — блок с настройками, дальше HTML (можно с Jinja-макросами
инфографики):

```html
<!--json
{
  "url": "novaya-stranica/",
  "h1": "Заголовок",
  "title": "Заголовок для вкладки браузера и выдачи",
  "description": "Описание для сниппета",
  "keywords": ["запрос 1", "запрос 2"],
  "lead": "Подзаголовок под H1",
  "priority": "0.7"
}
-->
{% import "ig.html" as ig %}
<p>Текст…</p>
{{ ig.panel_svg(programs) }}
```

Чтобы страница попала в верхнее меню — добавьте её в `nav` в `data/site.json`.

## Структура

```
build.py              генератор (Python + Jinja2)
data/
  site.json           название, адрес сайта, меню
  machine.json        программы, кнопки, размеры, таблица мер
  recipes.json        рецепты
  faq.json            вопросы и ответы для главной
  pages/*.html        контентные страницы с JSON-блоком настроек
templates/
  base.html           каркас: head, шапка, подвал, JSON-LD
  index.html          главная
  page.html           обычная страница
  recipe.html         рецепт
  recipes_index.html  список рецептов
  ig.html             макросы инфографики (SVG-схемы, карточка быстрого старта)
  icons.html          спрайт иконок
static/style.css      единственный CSS, светлая и тёмная тема
docs/                 СГЕНЕРИРОВАННЫЙ сайт — его и раздаёт GitHub Pages
```

## Оговорка

Сайт не является официальной документацией производителя. Оригинальной инструкции BM1250C с нормами
закладки в открытом доступе нет; материалы собраны по книге рецептов Judge JEA43 (печки на том же
контроллере), отзывам владельцев и практике. Это указано в подвале каждой страницы и на странице
про аналог.
